# Kairo 1.0.0

Première release installable. Le desk papier (six agents, modes strict / agressif / profit / intensif) est celui déjà publié. Cette version ajoute les paquets qui embarquent Python.

## Installer

- macOS Apple Silicon et Intel : `.dmg` (et un `.zip` de l'app). App non signée : clic droit > Ouvrir la première fois.
- Windows x64 : zip portable, lanceur `Kairo.cmd`.
- Linux x64 et arm64 : `.tar.gz`, `.deb`, AppImage.
- Docker : `ghcr.io/businesstradeforex-ui/kairo:1.0.0` (linux/amd64 et linux/arm64).

```bash
curl -fsSL https://raw.githubusercontent.com/businesstradeforex-ui/kairo/main/install.sh | bash
```

```powershell
irm https://raw.githubusercontent.com/businesstradeforex-ui/kairo/main/install.ps1 | iex
```

## IA locale

Rien n'est téléchargé à votre place. Au premier lancement, Kairo cherche Ollama (`127.0.0.1:11434`), LM Studio (`1234`) et llama.cpp (`8080`). S'il n'en trouve pas, le desk papier démarre quand même et http://127.0.0.1:8787/setup explique comment en brancher un.

## Sécurité

Paper par défaut. `KAIRO_LIVE_ENABLED` vaut 0 dans les lanceurs. Les archives ne contiennent ni clé, ni base, ni jeton. La clé de chiffrement est créée dans le dossier de données de l'utilisateur au premier lancement.
