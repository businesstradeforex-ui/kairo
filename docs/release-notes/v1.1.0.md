# Kairo 1.1.0

L'application Mac ouvre **sa fenêtre**, avec une icône dans le Dock et dans la barre des menus. Le navigateur n'est plus la fenêtre principale.

- Menu : À propos de Kairo, Préférences, Quitter.
- Barre des menus : état (actif ou pause), équité, Ouvrir, Pause ou Reprendre, Quitter.
- Fermer la fenêtre laisse le desk tourner (modifiable). Quitter l'arrête.
- Option « Ouvrir à la connexion ».
- Notifications macOS quand un trade se clôture.
- Écran d'accueil IA : modèles Ollama déjà installés, conseil selon la RAM et l'espace disque (on garde 4 Go libres), téléchargement avec barre de progression, test de connexion.

Sur un MacBook Air 16 Go avec peu de disque libre, le conseil est `qwen3:4b` (environ 2,8 Go). `gemma4:12b` est meilleur si vous avez la place. `qwen2.5:32b` est signalé comme trop lourd pour 16 Go. `qwen2.5:3b` peut être utilisé tout de suite s'il est déjà là.

Le `.dmg` est signé ad hoc, pas avec un certificat Apple. Si Gatekeeper bloque :

Réglages Système → Confidentialité et sécurité → **Ouvrir quand même**

ou `xattr -dr com.apple.quarantine /Applications/Kairo.app`

Paper trading. Le trading réel reste éteint. Aucun secret dans les archives.

Windows : même fenêtre (WebView2) dans le zip. Linux : le lanceur ouvre le navigateur.
